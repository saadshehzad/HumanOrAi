# HumanOrAI

HumanOrAI is a FastAPI project for building a classifier that distinguishes text written by a **human** from text generated by an **AI/LLM**.

The current API provides a placeholder prediction endpoint and an HC3 data-preparation pipeline. It does not load a trained classification model yet.

## Purpose

The goal is to build a model that predicts whether a given text was produced by a human or by AI.

## Dataset

The project currently uses the **HC3 (Human ChatGPT Comparison Corpus)** dataset from Hugging Face.

The workflow is built around the following stages:

1. Load the raw HC3 dataset
2. Clean and normalize answers
3. Create binary labels for human vs ChatGPT text
4. Split into train, validation, and test sets

## Run With Docker Compose

Build and start the API from the project root:

```bash
docker compose up --build
```

The service is available at <http://localhost:8000>. Stop it with `Ctrl+C`, or run it in the background with `docker compose up --build -d` and stop it later with:

```bash
docker compose down
```

The Compose configuration bind-mounts the project into `/app`, so datasets downloaded by the pipeline remain in the project directory on the host.

## API

FastAPI interactive documentation is available at <http://localhost:8000/docs>.

### Check text

`GET /predict` currently validates and echoes the supplied text; it does not make a human-versus-AI prediction yet:

```bash
curl --get http://localhost:8000/predict \
	--data-urlencode 'text=This is a sample sentence.'
```

An empty or whitespace-only value returns a prompt to enter text.

### Prepare the HC3 dataset

Run all three data-processing stages through the API:

```bash
curl http://localhost:8000/pipeline
```

The endpoint runs these scripts in order:

```bash
python3 src/scripts/load_hc3.py
python3 src/scripts/clean_hc3_data.py
python3 src/scripts/split_hc3_data.py
```

The first stage downloads the HC3 `all` configuration from Hugging Face. Unauthenticated requests work but may be subject to lower rate limits. To use a Hugging Face token, export `HF_TOKEN` and add it to the Compose service environment or pass it when using `docker run`:

```bash
export HF_TOKEN=your_token_here
docker compose up --build
```

The processed data is written to:

- `src/data/raw/hc3` for the downloaded raw dataset
- `src/data/processed/hc3` for the cleaned dataset
- `src/data/processed/hc3/train`
- `src/data/processed/hc3/validation`
- `src/data/processed/hc3/test`

To inspect the generated files:

```bash
find src/data -maxdepth 3 -type f
```

## Run With Docker Directly

The container starts the FastAPI app by default when you run the image.

```bash
docker build -t humanorai .
docker run --rm -p 8000:8000 -v "$PWD":/app -w /app humanorai
```

This starts the API on port 8000. Add `-e HF_TOKEN` when running the data pipeline with Hugging Face authentication:

```bash
docker run --rm -p 8000:8000 -e HF_TOKEN -v "$PWD":/app -w /app humanorai
```

The HC3 loader uses `trust_remote_code=True` because this dataset requires custom loading code. Use this only with the trusted HC3 repository; do not enable it for arbitrary dataset repositories.

## Scripts

### `load_hc3.py`
Loads the HC3 dataset from Hugging Face.

### `clean_hc3_data.py`
Extracts human and ChatGPT answers, removes duplicates, assigns binary labels, and saves a cleaned dataset.

### `split_hc3_data.py`
Splits the cleaned dataset into train, validation, and test sets with label stratification.

## Status

In development. Dataset loading, cleaning, and splitting are implemented; model training and real prediction are still to be added.
