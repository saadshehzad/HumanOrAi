# HumanOrAI

HumanOrAI is a machine learning project that classifies text as either written by a **human** or generated by an **AI/LLM**.

## Purpose

The goal is to build a model that predicts whether a given text was produced by a human or by AI.

## Dataset

The project currently uses the **HC3 (Human ChatGPT Comparison Corpus)** dataset from Hugging Face.

The workflow is built around the following stages:

1. Load the raw HC3 dataset
2. Clean and normalize answers
3. Create binary labels for human vs ChatGPT text
4. Split into train, validation, and test sets

## Data Pipeline

Run the dataset pipeline from the project root:

```bash
chmod +x run_hc3_pipeline.sh
./run_hc3_pipeline.sh
```

This script executes, in order:

```bash
python src/scripts/load_hc3.py
python src/scripts/clean_hc3_data.py
python src/scripts/split_hc3_data.py
```

The processed data ends up in the following folders:

- `data/raw/hc3` for the downloaded raw dataset
- `data/processed/hc3` for cleaned data
- `data/processed/hc3/train`
- `data/processed/hc3/validation`
- `data/processed/hc3/test`

## Scripts

### `load_hc3.py`
Loads the HC3 dataset from Hugging Face.

### `clean_hc3_data.py`
Extracts human and ChatGPT answers, removes duplicates, assigns binary labels, and saves a cleaned dataset.

### `split_hc3_data.py`
Splits the cleaned dataset into train, validation, and test sets with label stratification.
